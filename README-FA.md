# FLR-3 — رلهٔ خودی فلش (پلتفرم‌مستقل)

پایان وابستگی به کلادفلر: این رله **تک‌فایل و بدون هیچ وابستگی** است و روی هر جایی اجرا می‌شود — serv00 (رایگان)، هر VPS، یا هر هاست Node.js.

## فلش‌کلاد — داشبورد زندهٔ شبکه

**https://mohamad-1385.github.io/FLR-3/**

از همین صفحه می‌توانی (بدون هیچ نصبی، از مرورگر خودت):
- **تست زندهٔ همهٔ رله‌ها** از دل شبکهٔ خودت — همان مسیری که اپ می‌رود
- **دانلود آخرین نسخهٔ اپ فلش** (لینک مستقیم)
- **راهنمای لحظه‌به‌لحظهٔ نصب سرور serv00** + فرم تست و ثبت رلهٔ نو
- دیدن منابع بوت‌استرپ و نردبان خروجی

## چرا؟
کلادفلر ورکرهای پروکسی را لحظه‌ای بن می‌کند. FLR-3 روی **سرور خود شما** اجرا می‌شود:
- بدون اسکنر، بدون بنِ خودکار
- خروجی: مقاصد کلادفلری از دل رلهٔ GB (انگلیس) — بقیه مستقیم از سرور خودتان (اروپا)
- سازگار ۱:۱ با پروتکل بومی فلش (SMF-mux روی WSS) + فالبک VLESS

## راهنمای serv00 (رایگان — فقط گام ۱ دست خودت، بقیه یک خط)

### ۱) ثبت‌نام — serv00.com/register-account
- کشور **Iran** در لیست هست؛ ایمیل خودت را بزن (تأیید: چند ساعت تا ۷۲ ساعت — پوشهٔ Spam را هم ببین)
- یوزرنیم و پسورد قوی انتخاب کن — یادت بماند

### ۲) ساخت سایت Node.js (از پنل panel.serv00.com)
- منوی **WWW Websites → + Add new website → Advanced settings**
- Domain: `(یوزرنیم).serv00.net` · **Type: Node.js** · Node.js binary: جدیدترین (مثلاً node20)

### ۳) گواهی رایگان TLS (Let's Encrypt)
- در **WWW Websites** روی دامنه‌ات بزن → **SSL** → New certificate → Let's Encrypt → چند ثانیه تا Active

### ۴) نصب رله — فقط یک خط (در SSH)
با اپ **Termius** (گوگل‌پلی، رایگان) به `sX.serv00.com` وصل شو (نشانی سرور + یوزرنیم + پسورد — همگی در ایمیل تأیید) و این یک خط را پیست کن:

```sh
sh -c "$(fetch -q -o - https://raw.githubusercontent.com/Mohamad-1385/FLR-3/main/serv00-setup.sh)" _ USERNAME.serv00.net
```

(به‌جای `USERNAME.serv00.net` دامنهٔ خودت را بگذار)

اسکریپت خودش: رله را در محل درست (`domains/<دامنه>/public_nodejs`) نصب می‌کند + لودر Passenger می‌سازد + سایت را ری‌استارت می‌کند + نگهدارندهٔ ۵دقیقه‌ای (cron) می‌گذارد + تا دیدن `FLR-3 ok` تست می‌کند.

### ۵) ثبت در شبکهٔ فلش
نشانی `https://USERNAME.serv00.net` را در [فلش‌کلاد](https://mohamad-1385.github.io/FLR-3/) فرم «افزودن رلهٔ نو» تست کن و پیام آماده را بفرست — یا مستقیم برای ادمین بفرست.

به محض ثبت در `bootstrap.json` با `prio=1`، **همهٔ اپ‌های فلش** (بدون نصب دوباره) ظرف ۱۰ دقیقه به‌جای ورکر کلادفلر به **سرور خودت** وصل می‌شوند.

> راه راحت‌تر: اگر دست‌زدن به SSH نمی‌خواهی، فقط گام ۱ را بزن و «نشانی سرور + یوزرنیم + پسورد» را برای ادمین بفرست — نصب از راه دور انجام می‌شود و بعدش می‌توانی پسورد را عوض کنی.

## حالت پیشرفته (VPS / هاست دلخواه)

```sh
# بدون TLS (پشت nginx/پنل):
PORT=3000 node flr3-node.mjs

# با TLS مستقیم روی پورت 443:
FLR_TLS_CERT=/path/cert.pem FLR_TLS_KEY=/path/key.pem PORT=443 node flr3-node.mjs
```

متغیرها:
| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | 3000 | پورت شنود (Passenger خودش هندل می‌کند) |
| `FLR_UUID` | (همان فلش) | UUID احراز VLESS |
| `FLR_SMF_PATH` | (همان فلش) | مسیر WS پروتکل SMF |
| `FLR_VLESS_PATH` | (همان فلش) | مسیر WS فالبک VLESS |
| `FLR_EXITS_B64` | رله‌های GB/US/DE/FR | نردبان خروجی (base64 با کاما) |
| `FLR_BOOT_URLS` | — | فهرست رله‌های خروجی از راه دور (JSON) |

## بنچمارک و اثبات (P870-P871)
- تخلخل خود کد رله (لوپ‌بک): **۱۸۶ Mbps**
- زنجیرهٔ کامل GB از دل رله: loc=GB / colo=LHR اثبات زنده
- کلاینت SMF مرورگری فلش‌کلاد روی رلهٔ زنده: **۷/۷ PASS** (WS+هندشیک · DoH از دل تونل · mux · TCP+HTTP از دل تونل با IP خروجی · پرش‌های GB/US/DE)
- اندپوینت‌های کنترلی با CORS — داشبورد فلش‌کلاد مستقیم می‌خواند
